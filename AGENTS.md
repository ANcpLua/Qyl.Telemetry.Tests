# Qyl.Telemetry.Tests

Test support for Qyl telemetry: Qyl.Telemetry.Tests (receiver, evidence, policies, Collector fixtures) and Qyl.Telemetry.Tests.Capture (NativeAOT capture, used by AutoInstrumentation as a submodule). Suites: UnitTests, IntegrationTests, EndToEndTests. Each project's skill is under skills/. Build with ./build.sh (Fallout Check); pins live in Version.props and global.json.
